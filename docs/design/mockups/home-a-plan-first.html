Real features used

  • Planned session = a sessions row with status planned for today (MobileToday’s todays).
  • Phase and block pill from anchors.current_phase / current_block.
  • Readiness score and status, and form (TSB) band, from the current Today card.
  • This week: sessions done / planned and TSS logged, as computed today.
  • Recent: the last three completed sessions with label, duration, sRPE, avg watts.
